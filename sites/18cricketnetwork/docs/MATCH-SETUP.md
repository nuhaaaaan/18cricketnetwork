# Complete match setup

Match centre → open a match → Set up squads / Complete match setup.

Choose 2–11 existing player profiles for each playing side. Assign a captain and wicketkeeper from each selected squad (one player can hold both roles). Register both on-field umpires; third umpire, referee and scorer are optional. Player name, role, batting and bowling details are copied from registered profiles into the match snapshot.

Record match title, date, start time, location, venue, pitch, time zone, round, ball type and notes. The existing engine treats Team A as the first batting side: arrange the teams before setup. Optional toss details must agree with that order. Choose opening striker, non-striker and opposing bowler to initialize scoring without recording a delivery.

Setup may be revised before any event other than player selection. It is locked after scoring starts. Stale versions and invalid roster roles are rejected on the server. Competition setups follow the existing admin proposal and approval workflow. Existing legacy setups remain supported; their missing role details are labelled rather than invented.

Match dossier displays squads, C/WK roles and officials alongside the scoring console. Personal contact details are not collected here. This does not implement multi-innings Test cricket or automated DLS.
